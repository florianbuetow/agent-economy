# Complete the Agent Task Economy

## Why

The current platform implements the normal lifecycle but still has material concurrency, financial recovery, adjudication, privacy, artifact and participation gaps. The requested comprehensive audit and execution plan is `MASTERPLAN-TO-COMPLETE-THE-PROJECT.md` at the repository root.

## What Changes

Propose 26 dependency-ordered work packages, each with a new failing-test ticket and dependent implementation ticket (T-110–T-161), plus three accountable decision tickets (T-162–T-164). Preserve ratified v1 decisions and existing working functionality. Complete the human browser and independent-agent journeys, durable money/state recovery, safe assets, truthful observability and the full economic-vision validation.

This change is a planning artifact. No application fixes or ticket closures are claimed. Major policy questions Q-M1–Q-M3 are explicitly unresolved; other engineering work can proceed without them.

## Capabilities

- Modified capability: completion-backlog (new stable proposed acceptance requirements).
- Future implementation will amend agent-task-economy and domain API/test specs only with the corresponding accepted contracts.

## Impact

All seven services, shared auth/clients, autonomous agents, examples, schema, UI and test/operations tooling. Exact boundaries, risks and verification are in the root master plan. No new runtime dependency, deployment platform or frontend rewrite is required by this proposal.
